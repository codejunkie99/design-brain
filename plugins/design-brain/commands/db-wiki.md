# Design Brain Wiki

Generate project wiki pages and shared context pages.

## Usage

```bash
design-brain-memory wiki
```

## Output

Generates `.design-brain/wiki/` with:
- Per-project pages
- Shared token index
- Cross-project links

After running, read the wiki index and summarize what was generated.
